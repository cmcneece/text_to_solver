# TextToSolver Documentation

This directory contains documentation and examples for the TextToSolver package.

## Directory Structure

- `examples/` - Example scripts demonstrating TextToSolver usage
- `api/` - API documentation (to be added)
- `guides/` - User guides and tutorials

## Running Examples

Examples assume the package is installed. For development:

```bash
# Install in editable mode
pip install -e .

# Then run examples
python docs/examples/circle_and_line.py
```

## Documentation Files

- `guides/PERFORMANCE_GUIDE.md` - Performance optimization guide
- `guides/TESTING.md` - Test suite documentation
